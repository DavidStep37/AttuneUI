# 交互修订 · 2026-10-04

> 历史记录。当前实现与最终参数请先读 [Handoff-20261008.md](../Handoff-20261008.md)；例如 Slider 的收窄/内凹参数、Segmented 细颈和 Input 占位已继续调整。

基于新的 Slider 双层柱体示意图，对公共组件实现进行修订，原版与五套样式提案共用这套交互。

## Slider

- 浅色外轨道表示完整范围，深色内柱表示已选范围；小白点是操作手柄。
- 默认外轨道增高至 24px，与 Input 交互区域高度一致；深色内柱增高至 20px，内外层间距仍为 2px。交互行高度仍为 28px，默认白点仍为 4px。
- 内柱有独立的圆头轮廓，不再使用浅色矩形裁切表示已选部分。
- 默认白点直径 4px；手柄中心周围 12px 半径内悬停、实际操作或键盘聚焦时才扩大，默认展开直径仍为 14.4px，内柱和外轨道同时抬起。空白轨道悬停仅改变底色，不改变轮廓与尺寸。位置与数值映射保持一致。
- Slider 已移除质量/体积补偿与拖动方向造成的粗细变化。鼓包唤起、键盘聚焦和拖拽时，两端固定等量收窄，每侧默认内收 1.2px；离开手柄邻域后复原。
- 鼓包与端点之间有轻微细颈：中段每侧额外内凹 0.7px，再平滑回升连接圆头，上下边缘镜像。中段的内凹幅度固定，不随已选长度增加，也不会因反向拖动增厚。
- 鼓包过渡宽度由手柄尺寸决定，不随已选长度扩大；贴近手柄的肩部更紧凑。鼓包唤起与拖拽时右侧未选轨道也收细。
- 圆头修订：深色填充在手柄右侧使用独立 SVG 圆弧，避免鼓包衰减与端帽收口相乘造成尖角。外壳平滑包裹圆头，靠近极值时也保留弧形轮廓。
- 只有轻微拖尾随速度平滑变化，柱身粗细与瞬时速度解耦；鼓包位置始终与手柄锁定。文字和数值不参与形变。
- 越界拖动只改变视觉拉伸，逻辑值保持在 min/max 内。最小值和极小值均保留手柄下方完整、不透明的深色圆头；数值只控制填充长度，不再控制透明度，避免极小值被浅色轨道稀释成灰色。最大值填至外壳的内侧端点。
- 越界拉伸时，白色手柄保持全圆角矩形的胶囊轮廓。深色鼓包与外壳使用轨道曲线和胶囊轮廓的并集，自然包裹手柄的平直段与圆弧；不按左右端点切换形状，中段保留原来的鼓包。双层轨道与手柄共用纵向收缩：8px 拉伸时约收细 10.6%，上限 16%；拉伸回弹时同步恢复。正常范围内拖动不触发此收缩。
- 轨道与胶囊肩部采用平滑融合，融合强度向胶囊平直段连续衰减，消除两条轮廓直接取最大值造成的斜率突变。左右端点均检查肩部切线连续性，保留手柄周围的平直段。
- 点击轨道立即提交目标数值，手柄随后滑到对应位置；按步长取值以 min 为基准。
- 参数面板使用“两端收窄”“中段内凹”，移除 Slider 的“体积补偿”和“拖动粗细变化”；共享粗细补偿只影响 Timeline、Bezier 和 Segmented。
- 新增 `slider-fill`、`slider-thumb` 颜色 token：原版浅色为石墨填充和白点，深色为蓝灰填充和白点；提案使用各自强调色与主色混合的填充。

## 其他组件

- Input 默认无底色，在数字下方显示 20px 短下划线；悬停数字区域时描出较小的圆角外框，尺寸为原数字交互区域。仅悬停单位不触发。点击数字或下划线立即聚焦编辑，再将外框平滑放大；键盘聚焦也能完成描边和放大。
- 外框由两条对称路径绘制：从底部中央分别向左右延伸，经下角转向上方，沿两侧上行，再经上角向内转弯，在顶部中央闭合。四角为 90° 转向、5px 圆角。hover 描边期间不出现整块底色和高光；底色改为随后续聚焦放大的完整进度淡入，移除末尾 15% 才显现底色造成的突变感。
- 描边与放大使用独立进度，并按顺序衔接。hover 描边使用缓入缓出曲线，独立参数 `drawDuration` 默认 300ms（范围 100–4000ms）；聚焦放大参数 `expandDuration` 默认 480ms（范围 300–1000ms）。两者不再继承全局 `soft` 或旧 `input.spring`，避免保存的 0.02s 弹簧使绘制缩短到 50ms、放大缩短到 30ms。载入时仅迁移掉已废弃的 Input spring override，其余设置保留。快速点击时立即聚焦编辑，但先让描边从当前进度画到闭合，再开始放大，不同时移动正在绘制的轮廓。聚焦后每侧外扩 4px，水平方向另计 1px 描边，最终尺寸与前版一致。失焦但仍悬停时缩回小外框，移出且未聚焦时收回下划线。减弱动效时立即完成，并在页面开关旁明确标明绘制／缩放已关闭。描边颜色也直接跟随绘制与放大进度。
- 数字在显示与编辑时均水平居中，数字区域最小宽度 44px，单位独立预留 16px 列，间隔 4px；没有单位时也保留此列。分组和 Switch 关联区域展开完成后允许外框溢出，避免裁切；收起时恢复裁切。
- 单位右侧默认预留 4px 供展开时位移使用；展开后预留空间被消耗，单位列右缘与容器右缘对齐。外框与单位间距随描边绘制从 4px 变为 3px，数字中心与容器边界不动。失焦时同步恢复；修改外扩参数时，预留空间与位移使用同一数值。
- 编辑文字的选区底色使用 `slider-fill`，文字使用 `slider-thumb`，与当前主题的 Slider 保持一致。
- Input 下划线、hover 绘制、鼠标编辑和键盘聚焦统一使用 Slider 外轨道的 `border-subtle` 灰线，线宽仍为 1px；颜色保持一致，仅描边长度和外框尺寸随交互变化，不再出现激活态黑框或 Enter 确认后的橙色。原版公共聚焦环使用浅色主题的石墨灰、深色主题的浅灰蓝。
- Switch 悬停倍率改为 1.22，鼓包高度 5px，滑动形变 0.5；降低速度归一化阈值，使切换期间的拉伸可见，并以面积近似守恒方式压扁手柄。停下后恢复。
- Timeline 拖动读数使用短横杠，如 `0 – 600 ms`。
- 操作图标统一为 [Lucide](https://lucide.dev/)，采用命名导入，默认 14px、1.75 描边。覆盖按钮、面板折叠/关闭、Select、Bezier 展开和提案装饰图标。品牌 Logo 与交互几何仍为自绘 SVG。

## 验证方式

SliderField 改为两行：第一行左侧标签、右侧数字和单位，第二行完整宽度 Slider。头部左右边缘与滑轨一致；数字单位的 4px 预留空间仍在聚焦展开时消耗。此结构共用于展示卡片、调参面板、动效样例及五套提案。

共享参数现在常驻显示具体作用对象和调大/调小的结果，涵盖六项规则和五组弹簧。标题改为“跨组件默认值”，并说明组件单独覆盖后不再继承；不再声称每项均影响全部组件。

```sh
npm run build
node --experimental-strip-types scripts/test-slider-geometry.mjs
node scripts/check-interactions.mjs
node scripts/check-input-focus.mjs
node scripts/check-input-motion.mjs
node scripts/check-input-panels.mjs
node scripts/check-input-render.mjs
node scripts/check-proposals.mjs
```

浏览器脚本要求已启动本地开发服务器，使用仓库已有的 Puppeteer。`check-interactions.mjs` 支持 `CHROME_PATH` 和 `ATTUNE_URL`。截图输出至忽略目录 `.backup/interaction-review`。

`check-input-panels.mjs` 检查动效样例与弹出调参面板，覆盖默认和保存了极短弹簧参数的状态、节点未重新挂载、描边／放大持续时间，以及桌面和窄屏两行对齐。`check-input-render.mjs` 以实际截图像素确认左右侧边先于顶边出现；设置 `ATTUNE_INPUT_CONTEXT=sample` 可直接检查动效样例的面板，默认检查展示卡片。

几何检查覆盖双层容纳、0/100% 端点、两端等量收窄、轻微细颈、与方向和长度无关的柱身粗细、胶囊包裹、减弱形变，以及不同宽度/速度/形变倍率下的 756 组轮廓。浏览器检查覆盖拖动中停顿、反向、松手再抓取、越界、键盘、共享参数说明、输入下划线和编辑、Switch 动态拉伸、Timeline 标签，以及原版和五套提案的明暗色与减弱动效。Input 专项检查覆盖桌面/窄屏的数字居中、键盘聚焦、编辑、四边可见性、完整数字、失焦复原与嵌套区域展开/收起；逐帧检查描边的底边→侧边→顶边顺序、左右对称、连续进度和减弱动效。
