# 面板视觉与交互基准

这份基准用于在另一台电脑、另一个 AI 代理上接入时，拿到与维护仓库一致的面板。效果来自 `assets/attune-source` 中的组件源码。只要原样安装源码、按下表选字段类型，并且不覆盖 `.at-*` 样式，结果就应该与 `assets/reference/*.png` 一致。截图为 Chrome、1440×960、2× 像素密度、浅色主题、磨砂材质。

## 不要做的事

- 不要修改 `attune-source` 中的组件、`styles/attune.css` 或 `workbench/*`，也不要用宿主的 CSS（Tailwind preflight、全局 `button {}`、`* { box-sizing }` 以外的重置）覆盖 `.at-*`。需要调整外观时，先在维护仓库修改并重新打包。
- 不要自己拼装面板（PanelGroup / Row / Slider 等）来代替 `MotionWorkbench`；字段类型由 `MotionDefinition.fields` 决定，面板会自动选用正确的控件和属性。
- 不要给页面加 margin/transform 为面板让位：面板只悬浮，不推挤宿主。

## 字段类型 → 实际控件（由 MotionWorkbench 自动完成）

| `fields[].type` | 控件 | 关键属性 |
| --- | --- | --- |
| `number`（默认 / `control: "slider"`） | `SliderField`：标签与可编辑读数在上，滑轨在下 | 有范围的数值一律用这一种 |
| `number` + `control: "number"` | `NumberField`：只有读数 | 仅限没有合理上限的值 |
| `boolean` | `SwitchField`：标签在左，开关在行右侧 | — |
| `select` | `Row` + `Select width="100%"`：撑满到右边 | 选项多于约 8 个时用下拉 |
| `number`（启用预设且匹配 ≥2 个 token） | `TokenField`：token 下拉，“自定义”时下方展开连续滑块 + 数值输入 | 由 MotionWorkbench 自动选用 |
| `bezier` | stacked `Row` + `BezierEditor framed presetPicker="radial" size={180}` | 见下方曲线编辑器 |

## 尺寸与位置

- Toolbar：高 52px，宽度贴合内容（约 141px）；包含六点竖排拖动手柄、展开、播放（全部重播）、复制，没有分割线和菜单箭头。内容到四边的视觉距离都是 12px，圆角 26px。默认底部居中，可吸附六点（见 `01-toolbar.png`）。
- 单项重播菜单：鼠标悬停播放键弹出，键盘在播放键上按 ↑/↓ 打开，Esc 关闭。菜单宽 232px，随 Toolbar 停靠的位置居中或贴边，靠近上边缘时向下翻转（`02-toolbar-menu.png`）。
- 展开面板：宽 360px，外圆角 24px，首次出现在右上角（距右 16px、距顶 16px）。高度默认贴合内容：分组初始全部折叠（`03-panel-collapsed.png`，约 266px），展开分组时随之变高，最高到浏览器可视高度 − 48px 后在抬升面板内滚动。拖动底边设置高度上限（最小 260px，不超出视口，键盘聚焦手柄按 ↑/↓），面板仍贴合内容、不留空白；单击手柄不改变高度，双击恢复默认上限（可视高度 − 48）；上限与位置一起记忆。没有侧栏模式。
- 面板结构：外框为略深的底色（surface-sunken 与 border-subtle 混合，磨砂时半透明）；header 与 footer 直接在外框上，没有分隔线。中间是抬升面板：左右内缩 8px、圆角 16px、surface-panel 58% 半透明底（不是纯白）、1px border-subtle 描边（覆盖在内容之上）与轻阴影，内容在其中滚动（`03-panel.png`）。header 只有一行“Attune Motion”和收起按钮，内边距 16px 20px 14px；整个 header（按钮除外）都是拖动区域，光标为抓手。
- 抬升面板内：使用 Attune `ScrollArea` 且关闭滚动条（`scrollbar={false}`），任何滚动条都不显示；下方还有内容时底部 40px 渐隐（`fade`，遮罩实现，与背景无关），滚到底渐隐消失。不允许横向滚动。
- footer：内边距 14px 20px 16px。左侧“重播全部”28px 图标按钮（播放图标，无文字）；右侧预设开关、“重置全部参数”（未修改时禁用）和“复制完整 JSON”。

## 分组（每个动效一组）

- 头部从左到右：单项重播按钮（28px 图标按钮，与 footer“重播全部”纵向对齐、距面板左缘 20px）→ 标题 → 弹性留白 → 折叠箭头。没有编号徽标。分组描述不单独占一行（只作为标题悬停提示）。标题与控件左对齐在同一条线上，没有左缩进（`03-panel.png`）。
- 每组是抬升面板里的通栏区块（左右内边距 16px，标题行与第一个参数之间 8px）；组之间是贴满抬升面板宽度的 1px border-subtle 细线，不超出面板边缘。悬停（或键盘焦点在组内）时整块区段点亮为不透明的 surface-raised（浅色主题为纯白），比静止的面板更亮（`04-group-hover-card.png`）。
- 参数被修改后，参数名后面出现一个 6px 圆点，点击即恢复该项默认值。

## 曲线编辑器

- 字段名“缓动曲线”在外；下方是一个圆角 16px 的下沉容器，里面依次是曲线画布、数值输入框和预设圆盘 Select（`05-bezier-framed.png`）。
- 画布 180px，左下、右上两个角是直角（曲线端点正好在角上），另外两个角圆角 8px。曲线上的小点循环展示缓动效果，下方没有速度横条。
- 输入框与 Select 和画布同宽并居中，底色比容器亮，文字居中。输入框内容为 `x1, y1, x2, y2`，placeholder 为 `x1,y1,x2,y2`；回车或失焦时提交，Esc 还原，输入有误时短暂标红。没有匹配预设时，Select 显示“自定义”。
- 预设圆盘（半径 128、中心 48、间距 2.5、悬停鼓包 8 / 0.75 扇区）：当前选中项是扇区内侧（靠中心）一条 8px 粗、两端圆头的弯曲石墨色胶囊，与扇区圆角轮廓处处相距 2.5px，悬停时不变形。悬停任一扇区时，石墨色像液面一样从内缘向外缘升起（0.2s、无回弹），两侧始终贴合扇区的直线边，只有同心的前沿在移动，不是缩放；离开时液面退回内缘消失。
- 控制点超出默认范围（例如 back-out 的 y=1.56）时，画布在原框内自动缩小，曲线和手柄不会画出容器。

## 下拉（Select）

- 收起：浅灰底（surface-sunken）+ 1px border-subtle 的胶囊。
- 展开：原描边位置向外扩出 2.5px 的同色浅灰环，成为弹层底色；原触发器位置变成同尺寸、同圆角的白色表头胶囊；弹层保留 1px 外描边与轻阴影，外圆角 = 胶囊圆角 + 2.5（同心）。
- 选项行与高亮距弹层边 2.5px，文字与表头文字左对齐，无对勾列；当前值是一层 surface-hover 浅色胶囊底，石墨色悬停高亮在行间连续滑动，首次悬停时直接出现在该行。

## Token

- 预设开关（`ToggleButton`）关闭时是 28px 色板图标按钮，与旁边按钮一致；开启时为浅石墨色调底 + 较深描边（石墨 10% / 40%），图标转石墨色，宽度从图标处弹性展开出“启用预设”和右侧 ×（`06-tokens.png`），再点收起。选中态刻意比主按钮轻，不抢视线。
- token 字段（`TokenField`）：与 select 字段同一行布局，标签在左，下拉撑满到右边；触发器显示 token 名 + 浅灰数值（`short-5  300 ms`）。下拉每行同样是名称 + 数值，第一项“自定义 / 自由调节”；打开时当前 token 滚到中间，并以浅色胶囊底标出（见下方下拉样式）。
- 选“自定义”后触发器显示“自定义  420 ms”，下方展开一行连续滑块（无刻度）+ 右侧数值输入（`07-token-custom.png`）；选回 token 时收起。

## 自检

1. 用内置示例运行 `scripts/verify-example.mjs`（见 verification.md），或按 verification.md 逐项手动检查。
2. 在 1440×960 视口下截图对照 `assets/reference/`，重点看对齐、内边距、抬升面板与通栏分隔线、曲线容器和控件撑满情况。字体可能因系统而异，但布局、间距和控件结构应该相同。
