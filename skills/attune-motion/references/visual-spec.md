# 面板视觉与交互基准

这份基准用于在另一台电脑、另一个 AI 代理上接入时，拿到与维护仓库一致的面板。效果来自 `assets/attune-source` 中的组件源码。只要原样安装源码、按下表选字段类型，并且不覆盖 `.at-*` 样式，结果就应该与 `assets/reference/*.png` 一致。截图为 Chrome、1440×960、2× 像素密度、浅色主题、磨砂材质。

## 不要做的事

- 不要修改 `attune-source` 中的组件、`styles/attune.css` 或 `workbench/*`，也不要用宿主的 CSS（Tailwind preflight、全局 `button {}`、`* { box-sizing }` 以外的重置）覆盖 `.at-*`。需要调整外观时，先在维护仓库修改并重新打包。
- 不要自己拼装面板（PanelGroup / Row / Slider 等）来代替 `MotionWorkbench`；字段类型由 `MotionDefinition.fields` 决定，面板会自动选用正确的控件和属性。
- 不要给页面加 margin/transform 为面板让位：面板只悬浮，不推挤宿主。

## 字段类型 → 实际控件（由 MotionWorkbench 自动完成）

| `fields[].type` | 控件 | 关键属性 |
| --- | --- | --- |
| `number`（默认 / `control: "slider"`） | `SliderField`：标签与可编辑读数在上，滑轨在下 | 有范围的数值一律用这一种 |
| `number` + `control: "number"` | `NumberField`：只有读数 | 仅限没有合理上限的值 |
| `boolean` | `SwitchField`：标签在左，开关在行右侧 | — |
| `select` | `Row` + `Select width="100%"`：撑满到右边 | 选项多于约 8 个时用下拉 |
| `bezier` | stacked `Row` + `BezierEditor framed presetPicker="radial" size={180}` | 见下方曲线编辑器 |

## 尺寸与位置

- Toolbar：高 52px，宽度贴合内容（约 141px）；包含六点竖排拖动手柄、展开、播放（全部重播）、复制，没有分割线和菜单箭头。内容到四边的视觉距离都是 12px，圆角 26px。默认底部居中，可吸附六点（见 `01-toolbar.png`）。
- 单项重播菜单：鼠标悬停播放键弹出，键盘在播放键上按 ↑/↓ 打开，Esc 关闭。菜单宽 232px，随 Toolbar 停靠的位置居中或贴边，靠近上边缘时向下翻转（`02-toolbar-menu.png`）。
- 展开面板：宽 360px，默认高 660px，圆角 18px，首次出现在右上角（距右 16px、距顶 16px）。拖动底边可调高度（最小 260px，不超出视口），键盘聚焦底边手柄后按 ↑/↓ 调整；高度与位置一起记忆。没有侧栏模式。
- header：只有一行“Attune Motion”和收起按钮，内边距 16px 20px，底部一条分隔线。
- 内容区：上 12px、左右 24px、下 16px；使用 Attune `ScrollArea`，不显示原生滚动条（常态 4px 细条，靠近右缘变 8px 并出现外轨道），不允许横向滚动。
- footer：内边距 16px 20px，顶部分隔线。左侧“重播全部”；右侧“重置全部参数”（未修改时禁用）和“复制完整 JSON”。

## 分组（每个动效一组）

- 头部从左到右：编号徽标（01、02…）→ 标题 → 弹性留白 → 单项重播按钮 → 折叠箭头。标题与描述、控件左对齐在同一条线上，没有左缩进（`03-panel.png`）。
- 悬停（或键盘焦点在组内）时，整组显示淡底 + 细描边的卡片，圆角 20px；卡片向外扩 12px，与面板边框和 header 分隔线之间约 12px（`04-group-hover-card.png`）。组之间是一条很淡的细线，悬停卡片两侧的细线隐藏。
- 参数被修改后，参数名后面出现一个 6px 圆点，点击即恢复该项默认值。

## 曲线编辑器

- 字段名“缓动曲线”在外；下方是一个圆角 16px 的下沉容器，里面依次是曲线画布、数值输入框和预设圆盘 Select（`05-bezier-framed.png`）。
- 画布 180px，左下、右上两个角是直角（曲线端点正好在角上），另外两个角圆角 8px。曲线上的小点循环展示缓动效果，下方没有速度横条。
- 输入框与 Select 和画布同宽并居中，底色比容器亮，文字居中。输入框内容为 `x1, y1, x2, y2`，placeholder 为 `x1,y1,x2,y2`；回车或失焦时提交，Esc 还原，输入有误时短暂标红。没有匹配预设时，Select 显示“自定义”。
- 预设圆盘（半径 128、中心 48、间距 2.5、悬停鼓包 8 / 0.75 扇区）：当前选中项是扇区内侧（靠中心）一条 8px 粗、两端圆头的弯曲石墨色胶囊，与扇区圆角轮廓处处相距 2.5px，悬停时不变形。悬停任一扇区时，石墨色像液面一样从内缘向外缘升起（0.2s、无回弹），两侧始终贴合扇区的直线边，只有同心的前沿在移动，不是缩放；离开时液面退回内缘消失。
- 控制点超出默认范围（例如 back-out 的 y=1.56）时，画布在原框内自动缩小，曲线和手柄不会画出容器。

## Token

- footer 右侧“加载 Token”图标按钮（色板图标）打开面板内弹层：说明一行、预置 token 集按钮、JSON 文本框、“选择 JSON 文件”与“加载”。错误以红色小字显示在文本框下方。
- 已加载时，header 下方一条细栏：色板图标 + 集合名 + “N 个 token” + 右侧移除按钮（`06-tokens.png`）。
- token 字段（`TokenField`）：与 select 字段同一行布局，标签在左，下拉撑满到右边；触发器显示 token 名 + 浅灰数值（`short-5  300 ms`）。下拉每行同样是名称 + 数值，第一项“自定义 / 自由调节”；打开时当前 token 居中并打勾。
- 选“自定义”后触发器显示“自定义  420 ms”，下方展开一行连续滑块（无刻度）+ 右侧数值输入（`07-token-custom.png`）；选回 token 时收起。

## 自检

1. 用内置示例运行 `scripts/verify-example.mjs`（见 verification.md），或按 verification.md 逐项手动检查。
2. 在 1440×960 视口下截图对照 `assets/reference/`，重点看对齐、内边距、分组卡片、曲线容器和控件撑满情况。字体可能因系统而异，但布局、间距和控件结构应该相同。
