# 第一次接入的实际验证

用真实本地预览完成以下行为检查。记录浏览器、视口、命令及失败项，未执行的项目不能写成通过。

1. 页面正常显示，宿主字号/颜色没有被面板改变。默认 Toolbar 底部居中；鼠标拖动到六个点，松开吸附。拖动手柄用方向键也能切换。
2. 任一 Toolbar 点第一次展开都在右上角。拖动展开面板，收起再打开，位置保留；刷新、缩小视口后仍能找回。
3. 悬浮→侧栏→悬浮、侧栏→最小化都有尺寸过渡；侧栏时页面真实重排，收起/卸载恢复宽度。过渡途中反向操作没有跳位或残留占位。
4. 至少三组动效；修改 A 的数字，检查真实动画 timing/关键帧或视觉变化，B/C 不跟着重播。数字输入和 slider/键盘读数一致，单位转换准确。
5. 全部重播时三组均从初态重新播放；单项菜单仅重播一个，连续点击不会叠加旧动画。菜单 hover 可移入选择、上箭头可点击，键盘可导航和关闭。
6. 修改两组后复制：读取实际剪贴板并 JSON.parse，包含三组所有参数，修改值与页面相同。模拟剪贴板失败时显示手动复制内容，不能提示成功。
7. 390/320px 宽视口不横向溢出，展开面板仍可滚动和收起；侧栏有明确窄屏回退。系统减少动效时工具与宿主动画都降级，减少透明度时面板实底。
8. 类型检查和构建通过，浏览器无新错误。卸载工具后无浮层/Push 占位残留，用户页面仍可操作。

在 AttuneUI 维护仓库，复现命令为 `npm run build`、`npm run check:motion`（运行中的 localhost:5188）、`npm run skill:check`；跨机器设置 `CHROME_PATH`。截图在 `.backup/motion-review/`。外部消费者按自己的测试工具执行同等行为，不能照搬维护仓库脚本路径。
